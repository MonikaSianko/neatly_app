# Neatly — Family Budget

Budżet rodzinny. Money, neatly.

Next.js (App Router) + TypeScript, Tailwind, shadcn/ui (motyw Discord z tweakcn), Supabase.

## Rozwój

```bash
npm run dev
```

Otwórz [http://localhost:3000](http://localhost:3000).
